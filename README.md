# Twin Das — Developer Portfolio

A modern and responsive personal portfolio website showcasing my skills, projects, education, experience, and professional journey.

## 🌐 Live Portfolio

👉 [View Live Portfolio](https://twin-das-portfolio.onrender.com/)

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- Django
- SQLite
- Git & GitHub
- Render

## ✨ Features

- Responsive and modern UI
- About Me section
- Skills & technologies
- Projects showcase
- Education & experience timeline
- Contact form
- Django-powered contact message system
- Admin panel for managing contact messages
- Responsive navigation
- Scroll animations
